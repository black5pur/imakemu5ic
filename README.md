# 365 Journal

A daily journal for the imakemu5ic 365-day music plan. Each day shows one idea, its hook and how to make it. Log what happened and the rest of the plan re-flows around it:

- **Posted it**: the idea is done and the plan moves on.
- **Filmed / only practised / didn't get to it**: the idea carries forward and every later day shifts, or you can let it go.
- **Missed days** push the finish date back; extra posts pull it forward.
- **A post that takes off** adds three remixes of that format to the next week.
- **Posting days** can be switched off in Settings; the year stretches to fit.

Entries are stored only in your browser (localStorage). Use Settings > Export backup to keep a copy or move to another device.

Plain HTML, CSS and JavaScript. No build step, no tracking, no server.
